About me

Software that goes all the way to production.

I've been building full-stack products on my own alongside my degree, and I care about the parts that usually get skipped: rate limiting, secrets, deployment, and what happens when the free tier cuts you off.

My biggest builds are Ledgr for school fee management, an AI-powered hiring platform, and a database and API on Oracle Cloud that I led for a university group project. I write the code, design the schema, and configure the network it runs on.
